สิทธิ์เข้าเรียน

เมื่อระบบยืนยันการชำระเงินแล้ว ผู้เรียนจะได้รับสิทธิ์เข้าเรียนตามแพ็กที่ซื้อเป็นเวลา 30 วัน หรือตามระยะเวลาที่ระบุใน order

บัญชีและ access code

Access code ใช้สำหรับผู้สมัครที่ชำระเงินแล้วเท่านั้น ไม่ควรเผยแพร่หรือแชร์ให้บุคคลอื่น หากพบการใช้งานผิดปกติ 101 Future อาจระงับสิทธิ์เพื่อตรวจสอบ

เนื้อหาคอร์ส

วิดีโอ แบบฝึกหัด เอกสาร และเนื้อหาที่อยู่ในระบบเป็นส่วนหนึ่งของบริการเรียนของ 101 Future ห้ามนำไปขายต่อ เผยแพร่ซ้ำ หรือใช้นอกวัตถุประสงค์การเรียนโดยไม่ได้รับอนุญาต

การชำระเงิน
