    ขอบเขตการตรวจและความเป็นธรรม

    ใช้โจทย์ seed และ claim pack เดิม เปลี่ยนชื่อโมเดลและการเชื่อมต่อให้เป็น DGX Flash การค้นภาพรอบนี้ยังเลือกด้วย metadata เพื่อเทียบวิธีเดิม แล้วผู้ช่วยตรวจพิกเซลแยก ไม่ใช่การทดสอบ native vision ของ Flash

    ผลความหมายตรวจโดยผู้ช่วยหลัก ไม่ใช่ blind review หรือผู้ตรวจมนุษย์อิสระ เก็บผลตัวตรวจแบบตรงตัวแยกไว้ แม้ความหมายจะถูกแต่ข้อความไม่ตรงเกณฑ์ รูปแบบโค้ดที่ต้องปรับก่อนรันไม่ถูกนับเป็นผ่าน raw output ผล V100 เดิมใช้การตรวจคนละรอบ จึงไม่ใช่ blind head-to-head review

    งานภาพ seed 20202 รับช่วงหลัง HTTP timeout โดยใช้คำตอบเดิม ไม่เรียกโมเดลซ้ำและไม่เพิ่มงบ 8 ขั้นตอน เวลาแถวนั้นรวมช่วงกู้จึงไม่ใช้เทียบความเร็ว; งานภาพ seed 30303 และการตรวจ URL เปลี่ยนเฉพาะตัวโหลดเว็บให้มีเวลารวมจำกัด

    โค้ดรันเฉพาะใน sandbox ที่ทดสอบการปิด network/การอ่าน home/การเขียนนอกพื้นที่แล้ว; ถ้าไม่มี final code เพราะ token หมด จะระบุว่าไม่มีโค้ดให้รัน ไม่ปลอมผลเทสต์
